本模块按可观测性组件划分目录：`prometheus/prometheus.yml` 定义 scrape 任务，采集 nexus-ai、nexus-gate、milvus 及 Prometheus 自身指标；`loki/loki-config.yml` 以单机模式运行 Loki v2.9.5，使用文件系统存储并设置 168h 保留策略；`grafana/provisioning/datasources/prometheus.yml` 将 Prometheus 作为默认数据源，`grafana/provisioning/dashboards/dashboards.yml` 通过 file provider 加载 `nexuscockpit-overview.json` 仪表盘。三者均面向 Docker Compose 环境设计（目标地址使用 `host.docker.internal`、`prometheus:9090` 等容器名），由外部编排文件挂载到 `/etc/prometheus`、`/etc/loki/local-config.yml`、`/etc/grafana/provisioning/*` 路径生效。

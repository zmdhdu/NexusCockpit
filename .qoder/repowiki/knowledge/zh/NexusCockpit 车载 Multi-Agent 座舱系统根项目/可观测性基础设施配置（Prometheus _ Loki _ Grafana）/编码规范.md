- 每个组件使用独立 YAML 配置文件并按组件名分目录存放（prometheus、loki、grafana），便于按服务单独挂载或替换。
- Prometheus scrape 配置统一采用 `job_name` + `static_configs.targets` + `labels.service` 的结构，并通过 `metrics_path: /metrics` 暴露标准指标端点。
- 所有目标地址针对 Docker 开发环境使用 `host.docker.internal` 或容器 DNS 名称，避免硬编码宿主机 IP。
- Grafana 配置遵循官方 Provisioning API v1 格式，datasource 与 dashboard provider 均以 `apiVersion: 1` 声明。

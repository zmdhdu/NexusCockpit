- PowerShell 脚本统一以 `param()` 声明可选开关参数，并通过 `$ErrorActionPreference = 'SilentlyContinue'` 抑制非致命错误。
- 所有脚本通过 `Split-Path -Parent $MyInvocation.MyCommand.Path` 推导脚本所在目录，再向上取父目录得到项目根，避免硬编码路径。
- 日志文件统一写入 `logs/{backend,go,frontend}_logs/` 目录下，文件名格式为 `<服务名>_<yyyyMMdd_HHmmss>.log`。
- Python 修复类脚本采用函数式组织，每个文件针对特定 lint 错误或注释问题定义独立的 `fix_xxx()` 函数并在 `__main__` 中顺序调用。
- 需要修改源码的脚本使用精确字符串匹配定位目标代码块，通过 `assert` 断言确保替换位置存在后再执行写回。

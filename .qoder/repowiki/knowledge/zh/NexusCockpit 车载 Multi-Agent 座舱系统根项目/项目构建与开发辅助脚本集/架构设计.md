该模块为纯脚本集合，无包结构，按功能分为三类：
- Python 工具脚本：`export_openapi.py` 通过 `sys.path.insert` 动态导入 `nexus.main.create_app` 生成 OpenAPI JSON/YAML/Markdown；`fix_lint_errors.py`、`fix_comments.py`、`add_copyright.py`、`count_lines.py` 直接操作 `backend_design/nexus/agent/` 下的源文件进行一次性修复或统计。
- PowerShell 启动脚本：`start-all.ps1` 作为入口协调 uvicorn（:8000）、Go gateway（:9090）和 Next.js（:3000）三个子进程，分别输出到 `logs/{backend,go,frontend}_logs/` 带时间戳的日志文件；`start-backend.ps1`、`start-gateway.ps1`、`start-frontend.ps1` 提供单服务启动；`stop-all.ps1` 通过端口/进程名反向查找并终止对应进程。
- 系统集成脚本：`install-autostart.ps1` 使用 Windows Task Scheduler 注册 `NexusCockpitAutoStart` 任务实现登录自启。
依赖方向单向指向项目根目录（通过 `pathlib.Path(__file__).resolve().parent.parent` 计算 ROOT），脚本之间无相互 import，各自独立可执行。

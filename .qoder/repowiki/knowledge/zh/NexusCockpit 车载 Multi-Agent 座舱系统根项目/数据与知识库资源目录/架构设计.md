该模块为纯数据目录，按功能域划分为五个子目录：`food/` 存放食物列表、营养成分和餐厅信息（JSON 格式）；`knowledge/` 存放 FAQ、故障排查、车辆手册和语音指令等 Markdown 文档；`preferences/` 提供 `default_user.json` 和 `default_cockpit.json` 两套默认偏好模板，分别描述用户画像（音乐、饮食、位置、气候、导航）和座舱硬件设置（座椅、灯光、音响、空调、显示、隐私等）；`checkpoints/` 使用 SQLite 数据库 `nexus_checkpoints.db` 作为 LangGraph SqliteSaver 的会话状态持久化后端，通过 `thread_id` 隔离不同会话；根目录 `README.md` 通过环境变量映射各子目录路径（如 `FOOD_DATA_DIR`、`KNOWLEDGE_DATA_DIR`、`UPLOAD_DIR`、`TEMP_DIR`），实现运行时可配置的数据源定位。所有数据文件均为只读静态资源，由上层代码在启动时加载。

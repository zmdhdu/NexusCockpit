模块采用 Next.js 14 App Router 的目录即路由结构：`src/app/` 下每个子目录对应一个页面（admin、chat、cockpit、dashboard、dataplatform、middleware、settings、vehicle），根 `layout.tsx` 统一注入 Sidebar、GpsProvider、Sonner Toaster 和全局样式；`src/components/` 按功能域划分（chat、layout、ui、vehicle），`src/hooks/` 封装浏览器能力（音频录制、GPS、语音识别、异步请求），`src/stores/` 使用 Zustand 风格的模块级单例管理认证状态（auth-store）、音频状态（audio-store）、聊天会话（chat-store），`src/lib/` 集中 API 客户端（axios 实例+拦截器、TTS、工具函数、车辆事件），`src/types/` 统一定义前后端共享接口。

依赖方向严格单向：pages → components/hooks/stores/lib → api.ts → 后端 HTTP。认证流程由 `api.ts` 的请求拦截器自动附加 JWT Token 和 X-Cockpit-Id 多租户头，401 时自动刷新并重试；流式对话通过原生 fetch + ReadableStream 实现 SSE 事件推送，并自定义 StreamError 携带 HTTP 状态码。Dockerfile 采用多阶段构建配合 `next.config.js` 的 `output: 'standalone'` 生成最小运行镜像。

- 所有 API 调用集中在 `src/lib/api.ts`，通过 axios 实例的统一拦截器自动附加 Authorization 和 X-Cockpit-Id 请求头，组件层只调用导出的函数而非直接使用 axios。
- 跨模块共享的类型全部定义在 `src/types/index.ts` 并以 export interface 形式导出，避免在各文件中重复声明数据结构。
- 状态管理采用模块级单例 + 监听器模式（参考 auth-store.ts），通过 `useState` 订阅 `_listeners` 集合实现组件重渲染，不使用外部状态库。
- 流式响应统一使用原生 fetch + ReadableStream 实现 AsyncGenerator 异步生成器，并通过 AbortSignal 支持取消操作。
- 文件头部统一包含 MIT License 版权注释块，格式为 `(c) 2026 zhangmengdi (NexusCockpit)` 加源码链接。
- 环境变量通过 `process.env.NEXT_PUBLIC_*` 读取并在运行时注入，API 基础地址、默认用户、Token Key 等常量均从环境变量或 localStorage 加载。

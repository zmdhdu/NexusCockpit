该模块是一个纯数据仓库，按任务域划分子目录：`asr/sensevoice/` 存放 FunASR SenseVoice 的 PyTorch 权重与分词表；`embedding/bge-m3/` 存放基于 XLM-RoBERTa 的 sentence-transformers 嵌入模型；`reranker/bge-reranker-v2-m3/` 存放 safetensors 格式的重排序模型；`sv/cam_plus/` 存放 CAM++ 说话人验证的二进制与配置；`tts/cosyvoice/` 存放 CosyVoice 多组件权重（LLM、flow encoder/decoder、HiFi-GAN、speech tokenizer）；`llm/llama.cpp/` 包含跨平台 ggml/llama 动态库与 CLI 工具，`llm/qwen/` 放置 GGUF 量化大模型。各子目录均附带 README.md 说明下载方式与用法，依赖方向单向指向外部框架（FunASR、transformers、sentence-transformers、ModelScope），本模块不引入任何 Python 代码逻辑。

根目录作为整个 NexusCockpit 项目的编排与契约中心：
- 服务编排：docker-compose.yml 定义 app profile（nexus_gate Go 网关 → nexus_ai Python FastAPI → nexus_frontend Next.js）与基础设施 profile（Milvus+etcd+MinIO、Neo4j、Redis 8、MySQL、Langfuse、Loki、Prometheus、Grafana），通过 depends_on + healthcheck 保证启动顺序。
- 配置共享：根级 .env 是前后端与所有容器共享的环境变量源，Go 网关与 Python 后端通过相同 JWT_SECRET_KEY 完成跨语言鉴权；docker-compose.dev.yml 在开发模式下追加调试端口与日志挂载。
- 工程化入口：Makefile 提供 install/dev/lint/test/docker 等统一命令，封装 Python venv、Go mod、npm、Docker Compose 的调用，使多语言子模块对外暴露一致的 CLI。
- 数据与模型挂载：models/、data/、assets/ 通过 volume 映射到 nexus_ai 容器，被 config_observability、data_knowledge_preferences、shared_models 三个子模块共同消费。
- 可观测性贯穿：config_observability 中的 Prometheus/Loki/Grafana 配置文件由 docker-compose 直接挂载，Python 后端通过 Langfuse 上报追踪，形成 L7 可观测层对上层 Agent 与服务的统一监控。

## 简介
本指南面向 NexusCockpit 的新贡献者与日常开发者，提供从环境搭建、依赖管理、代码规范、测试策略、Git 工作流到调试与性能分析的完整开发流程说明。NexusCockpit 是一个企业级车载语音 Agent 项目，采用多语言栈（Python + Go + TypeScript），并集成 Multi-Agent、GraphRAG、MCP、Redis 语义缓存、Prometheus/Grafana/Loki/Langfuse 可观测性等能力。

## 项目结构
仓库采用“后端 Python + Go 网关 + 前端 Next.js”的三端分离结构，配合 Docker Compose 一键拉起中间件与基础设施。

- 后端服务：backend_design/nexus（FastAPI + LangGraph + RAG + ASR/TTS）
- 并发网关：backend_design/nexus_gate（Go Gin + JWT + WebSocket Hub）
- 前端应用：frontend_design（Next.js App Router + Zustand + Tailwind）
- 基础设施：docker-compose.yml（Milvus、Neo4j、Redis、MySQL、Langfuse、Prometheus、Grafana、Loki）
- 工程化：Makefile、CI、Pre-commit、pyproject.toml、package.json、go.mod

## 核心组件
- 后端（Python）
  - Web 框架：FastAPI + Uvicorn
  - Agent 编排：LangGraph（Supervisor + 专家节点 + Responder + Reflection + Reviewer）
  - RAG：Milvus（向量）、Neo4j（图谱）、BM25（全文）三路融合 + Rerank
  - 中间件：Redis 语义缓存、限流、会话存储
  - 数据库：aiomysql（异步 MySQL）
  - 可观测性：Langfuse、Prometheus、structlog
  - 配置：Pydantic Settings + python-dotenv
- 网关（Go）
  - 路由与鉴权：Gin + JWT
  - 实时通信：gorilla/websocket Hub
  - 指标：prometheus/client_golang
- 前端（TypeScript/Next.js）
  - 页面与组件：App Router、Tailwind CSS
  - 状态管理：Zustand
  - API 调用：axios
  - 类型检查：tsc（strict）

### 测试策略
- 单元测试（Python）
  - 使用 pytest，异步模式 auto，测试路径 tests
  - 示例覆盖 CockpitManager 与 TenantContext 的多座舱上下文隔离
- 集成测试（建议）
  - 基于 docker-compose 启动中间件后，对 Redis/Milvus/Neo4j/MySQL 进行端到端验证
- 前端测试（建议）
  - 使用 Jest/React Testing Library（按需引入）
- CI
  - GitHub Actions 对后端（ruff + pytest）、网关（go vet + build）、前端（tsc + build）进行校验

## 性能与质量
- 性能优化
  - 使用 Redis 语义缓存减少重复计算与 I/O
  - GraphRAG 三路融合 + Rerank 提升检索质量与效率
  - Go 网关高并发低内存，WebSocket Hub 支持实时通信
- 内存泄漏检测
  - Python：结合 memory_profiler 与 pprof（如适用）
  - Go：pprof 与 go tool trace
  - 前端：Chrome Performance 面板与 React DevTools Profiler
- 代码质量检查
  - Python：ruff + mypy + pytest-cov
  - Go：go vet + go build
  - TypeScript：eslint + tsc --noEmit

## 故障排查指南
- 常见问题
  - JWT 不一致导致 401：确保网关与后端使用相同 JWT_SECRET_KEY
  - 端口冲突：Windows Hyper-V 保留端口避让，参考 docker-compose.yml 端口映射
  - 模型未下载：按 README 指引下载 ASR/TTS/Embedding/Reranker 模型
- 诊断步骤
  - 检查各服务健康端点（/health）
  - 查看容器日志（docker compose logs）
  - 使用 Prometheus/Grafana 查看指标与告警
  - 使用 Langfuse 追踪 LLM 调用链

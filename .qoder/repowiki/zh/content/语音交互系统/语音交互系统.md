## 简介
本技术文档面向 NexusCockpit 语音交互系统的开发者与集成者，系统性阐述 ASR（SenseVoice）、TTS（CosyVoice）与声纹识别（CAM++）的集成方式、配置方法、音频预处理与后处理策略、实时流式对话流程与延迟优化技巧，并提供可操作的代码示例路径与最佳实践。文档覆盖音频格式支持、采样率配置、硬件加速选项，帮助读者快速完成模型接入与性能调优。

## 项目结构
NexusCockpit 将语音相关能力拆分为独立模块：
- ASR 引擎：封装 FunASR SenseVoice，提供离线本地识别能力
- TTS 引擎：封装 CosyVoice，提供离线本地合成与说话人选择
- 声纹服务：基于 CAM++ 提取特征，按座舱/用户隔离存储，实现注册与验证
- 配置中心：集中管理模型路径、阈值、采样率等参数
- API/WebSocket：对外暴露 REST 与实时双向通信接口

## 核心组件
- ASREngine（SenseVoice）
  - 懒加载模型，抑制第三方噪音日志，自动选择 CUDA/MPS/CPU
  - 支持多格式输入转换（WebM/MP3/M4A → 16kHz 单声道 WAV）
  - 结果后处理过滤纯标点噪声
- TTSEngine（CosyVoice）
  - 懒加载模型，JIT 加速，可选 fp16
  - 支持 SFT 说话人与零样本克隆模式
  - 输出 22050Hz WAV 片段并保存
- VoiceprintService（CAM++）
  - 通过 ModelScope pipeline 加载 CAM++ 模型
  - 按座舱/用户隔离存储 embedding（.npy）与原始音频
  - 注册需多次采集（默认3次），验证使用余弦相似度与阈值判定
- 配置与设备
  - ASRConfig 统一管理模型路径、阈值、采样率与环境变量映射
  - has_cuda() 检测 CUDA/MPS 可用性，驱动硬件加速

## 详细组件分析

### ASR 引擎（SenseVoice）集成与配置
- 模型加载
  - 懒加载，首次调用 load() 初始化 AutoModel，禁用更新检查，自动选择 cuda/cpu
  - 抑制 FunASR/PyTorch 噪音日志，避免启动干扰
- 转录流程
  - 接收音频路径，调用 generate(language="auto", use_itn=True)
  - rich_transcription_postprocess 后处理，过滤纯标点结果
- 音频格式支持
  - 路由层对 WebM/MP3/M4A/OGG 转换为 16kHz 单声道 WAV（优先 ffmpeg，其次 torchaudio/soundfile）
- 配置项
  - funasr_model_path、环境变量 FUNASR_MODEL_PATH
  - 采样率与通道数由转换层统一为 16kHz mono

### 声纹识别（CAM++）用户身份验证与个性化服务
- 模型加载
  - 通过 ModelScope pipeline 加载 speaker-verification 任务
  - 失败回退到 mock 模式并记录警告
- 注册流程
  - 提取 embedding（numpy 向量），按 cockpit_id/user_id 隔离存储 .npy 与原始音频
  - 累计注册次数达到阈值视为完成
- 验证流程
  - 遍历该座舱下所有用户的 embedding，计算余弦相似度，超过阈值即匹配成功
- 配置项
  - voiceprint_threshold、voiceprint_enroll_count、CAM++ 模型路径

### 实时语音对话的流式处理流程与延迟优化
- WebSocket 会话
  - 连接时通过 query token 进行 JWT 认证
  - 每 30 秒心跳 ping/pong，清理僵尸连接
- 流式执行
  - 接收 JSON 消息，构建初始 state，调用 agent_graph.stream_with_events 逐块推送
  - 完成后更新会话历史，统计端到端延迟
- 延迟优化建议
  - 预加载 ASR/TTS 模型，减少首帧延迟
  - 使用 JIT/ONNX（TTS 已支持 JIT）与 fp16 推理
  - 合理设置采样率与分片大小，降低网络传输开销
  - 利用缓存与会话历史，减少重复计算

## 性能考虑
- 模型加载与预热
  - 应用启动时预加载 ASR/TTS 模型，避免首次请求冷启动
  - 使用 JIT（TTS）与 fp16（有 GPU 时）提升推理速度
- 音频处理优化
  - 统一 16kHz 单声道输入，减少带宽与计算量
  - 优先使用系统 ffmpeg，其次 torchaudio/soundfile，提高兼容性
- 内存与并发
  - 使用临时文件与及时释放，避免内存泄漏
  - WebSocket 心跳与限流保护，防止僵尸连接与过载
- 硬件加速
  - has_cuda() 检测 CUDA/MPS，自动选择最优后端
  - 在 CPU 环境降级运行，保证可用性

## 故障排查指南
- ASR 无法识别
  - 检查模型路径是否存在且正确
  - 确认音频格式是否被转换（WebM/MP3/M4A/OGG）
  - 查看日志中“模型未加载”或“转换失败”提示
- TTS 合成失败
  - 检查 CosyVoice 模型路径与可用说话人列表
  - 确认输出路径权限与磁盘空间
- 声纹注册/验证异常
  - 确认 ModelScope 安装与 CAM++ 模型路径
  - 检查阈值配置与注册条数是否满足要求
  - 查看 embedding 文件是否完整（.npy）

## 引言
NexusCockpit 是一个企业级车载语音 Agent 系统，采用 7 层分层架构，融合 Multi-Agent 协同、GraphRAG 检索增强、语义缓存与 MCP 协议等前沿技术。系统以“座舱控制 + 运营总览”为核心形态，面向真实车载交互场景提供高可用、可观测、可演进的 AI 能力底座。其差异化在于：
- 多智能体并行编排与反思校验闭环，保障输出质量与安全；
- 向量+图谱+BM25 三路 RRF 融合检索，提升召回与排序精度；
- Go 并发网关承载鉴权、限流与 WebSocket Hub，Python FastAPI 专注 AI 推理与业务编排；
- 本地化全栈中间件（Milvus/Neo4j/Redis/MySQL）与云端 LLM 降级策略并存；
- 面向座舱的多租户隔离与个性化服务（声纹识别、偏好注入）。

这些特性使 NexusCockpit 在车载语音交互领域具备更强的稳定性、可控性与扩展性。

## 项目结构
项目采用前后端分离与模块化分层组织：
- 后端 Python（FastAPI）：AI 服务、Agent 编排、RAG、记忆、技能、车控适配、MCP、可观测性等；
- 后端 Go（Gin）：并发网关，负责 JWT 鉴权、限流、反向代理与 WebSocket Hub；
- 前端 Next.js：座舱控制台、聊天页、数据中台、监控看板、设置与管理后台；
- 基础设施：Docker Compose 编排 Milvus、Neo4j、Redis、MySQL、Prometheus、Grafana、Loki；
- 模型与数据：ASR/TTS/Embedding/Reranker 模型文件与知识库、用户偏好等。

## 核心组件
- 7 层分层架构：从基础设施到可观测层的清晰解耦，便于独立演进与替换；
- Multi-Agent 工作流：Supervisor 调度 5 个专家（车辆、导航、生活方式、健康、闲聊），经 Responder 汇总、Reflection 反思、Reviewer 终审，形成强约束闭环；
- GraphRAG 检索：向量（Milvus）、图谱（Neo4j）、BM25 全文三路召回，RRF 融合后由 bge-reranker-v2-m3 重排；
- 语义缓存与限流：Redis 8 RediSearch KNN 语义缓存，滑动窗口限流，副作用隔离；
- 车控总线：Mock/HTTP/MCP stdio 三模式适配，统一 Skill 调用；
- 可观测性：Langfuse Tracing、Prometheus Metrics、Grafana 面板、结构化日志；
- 混合架构：Go 网关高并发处理请求入口，Python FastAPI 专注 AI 推理与业务编排。

## 详细组件分析

### Multi-Agent 协同架构（Supervisor + 5 Experts）
- Supervisor 节点负责记忆召回、意图路由与专家分派决策；
- 5 个专家并行执行（车辆、导航、生活方式、健康、闲聊），结果汇聚至 Responder；
- Responder 生成自然语言回复或合成工具返回的结构化数据；
- Reflection 进行事实性/一致性/无幻觉检查，必要时自我修正；
- Reviewer 作为全局终审关卡，记录指标并持久化记忆；
- Output Gateway 对最终输出做安全校验，确保不泄露内部状态。

### GraphRAG 融合检索
- 三路召回：向量（Milvus 语义相似度）、图谱（Neo4j 用户画像与关系遍历）、BM25（全文关键词匹配）；
- RRF 融合排序：按倒数排名加权合并，平衡不同路径的贡献；
- Rerank 重排：bge-reranker-v2-m3 对 Top-K 候选进行精细排序；
- 支持用户记忆检索与食材库检索等特定场景。

## 性能与可扩展性
- 并发与吞吐：Go 网关基于 Goroutine 与 Gin 框架，支撑千级 WebSocket 连接与高 QPS；
- 检索性能：Milvus HNSW 索引与 Neo4j Cypher 查询优化，结合 RRF 与 Rerank 提升准确率；
- 缓存命中：Redis 语义缓存减少重复计算，滑动窗口限流保护后端；
- 降级策略：云端 LLM 不可用时自动降级至本地 llama.cpp，保障可用性；
- 可观测性：Prometheus 指标与 Langfuse 追踪覆盖端到端延迟与错误率。

## 故障排查指南
- 启动失败：检查 .env.local 与 JWT 密钥一致性，确认中间件容器状态；
- 鉴权失败：核对网关与后端 JWT_SECRET_KEY 一致；
- 检索异常：验证 Milvus/Neo4j 连接与索引状态；
- Agent 无响应：查看 SupervisorGraph 日志与 checkpoint 持久化；
- 限流触发：调整网关 RateLimitQPS 或后端限流阈值；
- 模型加载慢：ASR/TTS 模型后台预加载，首次请求可能较慢。

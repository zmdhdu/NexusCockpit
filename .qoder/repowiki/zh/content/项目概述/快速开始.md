## 简介
本快速开始指南面向首次接触 NexusCockpit 的用户，目标是帮助你在 15 分钟内完成环境搭建、服务启动与验证，并掌握常用 API（文本对话、SSE 流式输出、车控命令、WebSocket 连接）的使用方法。系统采用 Docker 编排基础设施，Python FastAPI 后端、Go 网关与 Next.js 前端协同工作，支持本地模型与云端 LLM 降级。

## 项目结构
NexusCockpit 采用分层与模块化组织：
- 基础设施层：Docker Compose 编排 Milvus、Neo4j、Redis、MySQL、Prometheus、Grafana、Loki、Langfuse 等中间件
- 应用层：Python FastAPI 后端（AI Agent、RAG、ASR/TTS、车控适配）、Go 并发网关（鉴权、限流、WS Hub）、Next.js 前端
- 配置中心：按子系统拆分的环境变量与 Pydantic Settings 管理
- 脚本与工具：一键启动、日志收集、初始化脚本

  - Agent 工作流(Supervisor + 专家 Agent)

## 性能与稳定性建议
- 语义缓存：对非车控、非上下文敏感的查询开启缓存，降低 LLM 调用与检索开销
- SSE 心跳：合理设置心跳间隔，避免代理/防火墙超时断连
- 限流：基于 Redis 滑动窗口限流，保护后端资源
- 异步任务：AI 生成任务池与 SSE 解耦，页面切换不中断生成
- 监控：Prometheus 指标采集与 Grafana 看板，关注 API 延迟、Agent 耗时、缓存命中率

## 故障排查指南
- 健康检查：
  - 后端：http://localhost:8000/health
  - 网关：http://localhost:8080/health
- 常见问题：
  - 网关与后端 JWT 密钥不一致导致 401：确保 Go 网关与 Python 后端使用相同 JWT_SECRET_KEY
  - Milvus/Neo4j 连接失败：检查 docker-compose 服务状态与端口映射
  - Redis 密码与端口：确认 .env 中的 REDIS_PASSWORD 与端口映射（宿主机 16379→容器 6379）
  - 模型下载失败：确保磁盘空间充足，按 README 指引下载 ASR/TTS/声纹模型
  - CORS 跨域问题：调整 ServerConfig.cors_origins 允许前端域名
- 日志位置：
  - 后端：logs/backend_logs/*.log
  - 网关：logs/go_logs/*.log
  - 前端：logs/frontend_logs/*.log

## 附录：15分钟上手清单
- 环境准备
  - 安装 Docker、Docker Compose、Python 3.10+、Go 1.21+、Node.js 18+
  - 克隆仓库并进入项目根目录
- 启动基础设施
  - 运行 docker compose up -d，等待所有中间件健康
- 安装后端环境
  - 创建虚拟环境并安装依赖（或使用 Makefile install）
- 下载 AI 模型
  - 使用 modelscope 下载 SenseVoice、CAM++、CosyVoice 模型至 models 目录
- 配置环境变量
  - 复制 .env.example 为 .env，填写 ARK_API_KEY、LLM_MODEL、EMBEDDING_MODEL 等
- 启动服务
  - 启动后端：uvicorn nexus.main:app --host 0.0.0.0 --port 8000
  - 启动网关：go run cmd/main.go（确保 JWT_SECRET_KEY 一致）
  - 启动前端：npm run dev
- 验证与访问
  - 健康检查：/health
  - API 文档：http://localhost:8000/docs
  - 前端界面：http://localhost:3000/cockpit
- API 示例
  - 文本对话：POST /cockpit/{id}/chat
  - SSE 流式：POST /cockpit/{id}/chat/stream
  - 车控命令：POST /cockpit/{id}/vehicle/command
  - WebSocket：ws://localhost:8080/cockpit/{id}/ws/chat
  - 获取 Token：POST /auth/token

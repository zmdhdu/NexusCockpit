## 引言
NexusCockpit 是一个企业级车载语音 Agent 系统，采用 7 层分层架构，融合 Multi-Agent 协同、GraphRAG 检索增强、语义缓存与 MCP 协议等前沿技术，提供“座舱控制 + 运营总览”的一体化体验。系统以 Go 高并发网关为入口，Python FastAPI 承载 AI 能力，Next.js 构建前端界面，并通过 Docker Compose 一键编排 Milvus、Neo4j、Redis、MySQL、Prometheus、Grafana、Loki 等基础设施，支持本地离线部署与云端 LLM 降级。

核心价值：
- 多智能体协同：Supervisor 调度 5 个专家（车控、导航、生活、健康、闲聊），并行执行后统一汇总、反思与审查，保障输出质量与安全。
- GraphRAG 三路融合：向量（Milvus）+ 图谱（Neo4j）+ BM25（全文）经 RRF 融合与 Rerank 重排，提升召回与排序精度。
- MCP 标准化协同：跨进程/服务任务分发、状态同步、结果回调、异常上报与心跳保活，便于扩展与集成。
- 企业级中间件：Redis 语义缓存（KNN）、限流、会话持久化、熔断器、异步任务池，保障高可用与高性能。
- 可观测性：Langfuse 追踪、Prometheus 指标、Grafana 面板、Loki 日志，覆盖全链路监控。

技术特色：
- 7 层分层架构清晰解耦，职责单一，易于演进与替换。
- 本地化优先：固定本地 Docker 中间件，LLM 可选云端 API 或本地 llama.cpp 自动降级。
- 语音交互闭环：ASR（SenseVoice）+ TTS（CosyVoice）+ 声纹识别（CAM++），实现个性化语音服务。
- 前后端分离：Go 网关承担鉴权、限流、WebSocket Hub；FastAPI 暴露 REST/SSE/WebSocket；Next.js 提供现代化 UI。

企业级应用场景：
- 车载语音助手：自然语言对话、车控指令、导航、天气、日程提醒、健康建议等。
- 多座舱隔离：每座舱独立数据与状态，支持跨座舱统计与运营看板。
- 知识问答与搜索：结合用户画像与历史记忆，提供精准回答与个性化推荐。
- 运维监控：中间件健康、API 延迟、Agent 耗时、缓存命中率等可视化监控。

## 核心组件
- 配置中心：集中管理 LLM、数据库、缓存、服务器、第三方服务等配置，支持 .env.local 覆盖与环境变量注入。
- 应用入口：FastAPI 生命周期管理，初始化 Embedding、向量/图谱存储、车控适配器、语义缓存、限流、会话、Langfuse、Agent 工作流、MCP Server、提醒扫描器等。

- MCP Server：标准化任务分发、状态同步、结果回调、异常上报、心跳保活。
- Go 网关：JWT 鉴权、座舱级限流、非 AI 请求直处理、AI 请求反向代理到 Python、WebSocket Hub 管理连接。

## 关键组件详解

### Multi-Agent 工作流（Supervisor + 5 Experts）
- Supervisor 节点负责记忆召回、意图路由与专家分派决策。
- Dispatch 节点通过 asyncio.gather 并行调用专家，合并结果。
- Responder 节点汇总专家输出，进行 Tool→LLM 合成或闲聊生成。
- Reflection 节点进行事实性、一致性、无幻觉检查，必要时修正回复。
- Reviewer 节点进行终审校验，记录指标并存储记忆。

## 性能与可观测性
- 语义缓存：Redis 8 RediSearch KNN 向量缓存，副作用隔离，避免重复计算。
- 限流：Redis 滑动窗口限流，保护后端资源。
- 异步任务池：GenerationTaskPool 脱离 SSE 连接生命周期，保证长任务稳定执行。
- 可观测性：Langfuse 追踪 LLM 调用，Prometheus 采集指标，Grafana 可视化，Loki 聚合日志。

优化建议：
- 合理设置缓存 TTL 与淘汰策略，平衡命中率与内存占用。
- 根据负载动态调整限流阈值，避免雪崩效应。
- 监控 LLM 调用延迟与错误率，及时切换降级模型。

## 快速开始指南
环境要求：
- Python 3.10+、Go 1.21+、Node.js 18+、Docker 24+、Docker Compose 2.20+、Git 2.30+

步骤：
1. 克隆项目并进入目录。
2. 启动基础设施：docker compose up -d
3. 安装后端依赖：pip install -r backend_design/requirements.txt 或使用 make install
4. 下载 AI 模型：SenseVoice、CAM++、CosyVoice（约 3.5GB）
5. 配置环境变量：复制 .env.example 为 .env，填入 ARK_API_KEY 等必要参数
6. 启动后端服务：uvicorn nexus.main:app --host 0.0.0.0 --port 8000 --reload
7. 启动 Go 网关：go run backend_design/nexus_gate/cmd/main.go
8. 启动前端：cd frontend_design && npm install && npm run dev
9. 访问应用：前端 http://localhost:3000/cockpit，API 文档 http://localhost:8000/docs

验证方法：
- 后端健康检查：curl http://localhost:8000/health
- 网关健康检查：curl http://localhost:8080/health
- 登录获取 Token：POST /auth/token
- 发送聊天请求：POST /cockpit/{id}/chat

## 故障排查
常见问题：
- LLM API Key 为空：检查 .env.local 中 ARK_API_KEY 是否配置正确
- Milvus/Neo4j 连接失败：检查 docker compose 服务是否正常运行，网络是否互通
- JWT 密钥不一致：确保 Go 网关与 Python 后端使用相同 JWT_SECRET_KEY
- ASR/TTS 模型加载慢：首次请求会阻塞，后续请求直接使用已加载模型
- 缓存未命中：检查 Redis 连接与密码配置，清理旧缓存条目

调试技巧：
- 查看日志文件：logs/go_logs/gateway_*.log
- 使用 Grafana 面板监控中间件状态
- 启用 Langfuse 追踪 LLM 调用链

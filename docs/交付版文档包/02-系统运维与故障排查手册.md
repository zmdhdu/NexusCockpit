## 2. 快速部署

### 2.1 本地开发环境

```bash
# 1. 克隆项目
git clone https://github.com/zmdhdu/NexusCockpit.git
cd NexusCockpit

# 2. 创建环境配置
cp .env.example .env.local
# 编辑 .env.local 填入 API Key 等

# 3. 启动中间件 (Docker)
docker compose up -d

# 4. 启动后端
cd backend_design
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m nexus.main

# 5. 启动前端
cd ../frontend_design
npm install
npm run dev

# 6. 启动 Go 网关 (可选)
cd ../backend_design/nexus_gate
go run cmd/main.go
```

### 2.2 Docker 全栈部署

```bash
# 1. 配置环境
cp .env.prod.example .env.prod
# 编辑 .env.prod 填入生产配置
export APP_ENV=prod

# 2. 启动全栈 (中间件 + 应用)
docker compose --profile app up -d

# 3. 验证服务
curl http://localhost:8080/health    # Go 网关健康检查
curl http://localhost:8000/          # Python 后端
curl http://localhost:3000           # 前端
```

### 2.3 验证部署

```bash
# 健康检查
curl http://localhost:8080/health
# 预期: {"status":"healthy","service":"nexus_gate",...}

# 中间件状态
curl http://localhost:8080/middleware/
# 预期: 所有中间件 "online"

# API 文档
open http://localhost:8000/docs
```

## 3. 配置说明

### 3.1 环境文件分层

| 文件 | 用途 | 加载条件 |
|------|------|----------|
| `.env.local` | 本地开发 | `APP_ENV=local` 或未设置 (默认) |
| `.env.prod` | 生产环境 | `APP_ENV=prod` |
| `.env` | 兼容回退 | 当 .env.local/.env.prod 不存在时 |

### 3.2 关键配置项

#### LLM 模式切换

```bash
# 云端模式 (推荐)
LLM_PROVIDER=cloud
ARK_API_KEY=your_api_key

# 本地模式
LLM_PROVIDER=local
LLAMA_CPP_MODEL_PATH=./models/llm/qwen/Qwen3.5-4B-Q4_K_M.gguf

# 云端 + 本地降级
LLM_PROVIDER=cloud
LLM_FALLBACK_ENABLED=true
```

#### 座舱配置

```bash
COCKPIT_COUNT=1                          # 座舱数量
COCKPIT_THEMES=#4fc3f7,#66bb6a,#ab47bc  # 主题色 (逗号分隔)
COCKPIT_NAMES=座舱1,座舱2,座舱3           # 座舱名称
```

#### 智能记忆管理

```bash
MEMORY_COMPRESS_THRESHOLD_TURNS=8        # 压缩阈值 (轮)
MEMORY_KEEP_RECENT_TURNS=5               # 保留最近轮数
MEMORY_MAX_HISTORY_LEN=20                # 最大历史条数
MEMORY_CONTEXT_TOKEN_RATIO=0.7           # 上下文 token 比例
```

## 5. 监控告警

### 5.1 Prometheus 指标

访问 Prometheus: `http://localhost:9200`

关键指标:
- `nexus_requests_total` — 请求总数 (按 endpoint/method/status)
- `nexus_request_latency_seconds` — 请求延迟
- `nexus_active_connections` — 当前并发连接数
- `nexus_agent_invocations_total` — Agent 调用次数
- `nexus_cache_hits_total` / `nexus_cache_misses_total` — 缓存命中/未命中

### 5.2 Grafana 看板

访问 Grafana: `http://localhost:3001` (admin/admin)

预置看板:
- API 性能看板 (延迟 P50/P95/P99)
- Agent 活动看板 (调用次数/延迟/错误率)
- 缓存命中率看板
- 中间件状态看板

### 5.3 Langfuse 追踪

访问 Langfuse: `http://localhost:3101`

功能:
- 链路追踪 (Trace → Span)
- LLM 调用记录 (模型/Token/延迟)
- Prompt 模板管理
- A/B 测试

## 6. 日志管理

### 6.1 日志位置

| 服务 | 日志路径 |
|------|----------|
| Python 后端 | `backend_design/nexus/logs/backend_logs/` |
| Go 网关 | `logs/go_logs/` 或 `$LOG_DIR` |
| 前端 | `logs/frontend_logs/` |
| Docker | `docker compose logs <service>` |

### 6.2 日志级别

```bash
# 开发环境 (详细日志)
LOG_LEVEL=DEBUG

# 生产环境 (仅警告+错误)
LOG_LEVEL=WARNING
```

### 6.3 数据保留策略

系统自动清理过期日志 (默认 30 天)，由 `DataRetentionManager` 管理。

```bash
# 查看保留配置
DATA_RETENTION_DAYS=30     # 日志保留天数
DATA_RETENTION_CHECK_HOURS=24  # 检查间隔
```

## 8. 故障排查

### 8.1 服务无法启动

```bash
# 检查端口占用
netstat -tlnp | grep -E '8000|8080|3000|16379|19530|17687'

# 检查 Docker 资源
docker system df
docker system prune -f

# 检查日志
docker compose logs --tail=100 nexus_ai
```

### 8.2 LLM 调用失败

```bash
# 检查 API Key
curl -H "Authorization: Bearer $ARK_API_KEY" $ARK_BASE_URL/models

# 检查网络
curl -v $ARK_BASE_URL

# 降级到本地 LLM
LLM_PROVIDER=local
```

### 8.3 中间件连接失败

```bash
# 检查中间件状态
curl http://localhost:8080/middleware/

# 检查特定中间件
curl http://localhost:8080/middleware/redis
curl http://localhost:8080/middleware/mysql

# 检查 Docker 网络
docker network inspect nexuscockpit_default
```

### 8.4 内存不足

```bash
# 检查内存使用
docker stats

# 调整 Docker 资源限制 (docker-compose.yml)
```

## 10. 常见报错与解决方案

### 10.1 ASR 语音识别无响应

| 症状 | 可能原因 | 解决方案 |
|------|----------|----------|
| 录音后无文字返回 | 模型文件未下载 | 检查 `models/asr/sensevoice/` 目录是否有 `model.pt` |
| 识别延迟 > 5 秒 | CPU 推理（无 GPU） | 安装 CUDA 版 PyTorch 或降低模型精度 |
| 识别结果为乱码 | 采样率不匹配 | 确保麦克风采样率为 16kHz 单声道 |
| 启动报 `FileNotFoundError` | 模型路径错误 | 检查 `.env` 中 `FUNASR_MODEL_PATH` 配置 |

### 10.2 TTS 语音合成异常

| 症状 | 可能原因 | 解决方案 |
|------|----------|----------|
| 合成音频为空 | CosyVoice 模型未加载 | 检查 `models/tts/cosyvoice/` 目录 |
| 音频有杂音 | 采样率不匹配 | TTS 默认输出 22050Hz，确认扬声器支持 |
| 合成延迟过长 | GPU 显存不足 | 降低 `LLAMA_CPP_GPU_LAYERS` 或使用 CPU |
| 启动报 CUDA OOM | GPU 显存不够 | 关闭其他 GPU 进程或使用 CPU 模式 |

### 10.3 语义缓存不生效

```bash
# 1. 检查 Redis 是否运行
docker exec nexus-redis redis-cli ping
# 预期: PONG

# 2. 检查 RediSearch 模块是否加载
docker exec nexus-redis redis-cli MODULE LIST
# 预期: 包含 search 模块

# 3. 检查缓存统计
curl http://localhost:8000/admin/cache/stats
# 预期: 返回 hits/misses 统计

# 4. 车控指令不会命中缓存（设计如此，副作用隔离）
```

### 10.4 Agent 对话质量下降

| 症状 | 可能原因 | 解决方案 |
|------|----------|----------|
| 回答不相关 | LLM 模型版本变更 | 检查 `.env` 中 `LLM_MODEL` 配置 |
| 重复回答 | 会话历史污染 | 清理 Redis 中的会话缓存 |
| 车控指令不执行 | 意图路由失败 | 检查后端日志中 intent 字段 |
| 搜索结果过时 | Tavily API Key 失效 | 检查 `TAVILY_API_KEY` 配置 |
| 回复中出现幻觉 | LLM 编造对话历史 | 系统已内置反思校验，如仍出现请检查 `responder.py` |

### 10.5 前端页面白屏

```bash
# 1. 检查前端构建
cd frontend_design
npm run build
# 如有报错，修复 TypeScript 类型错误

# 2. 清除缓存
rm -rf .next
npm run dev

# 3. 检查浏览器控制台 (F12)
# CORS 错误 → 检查后端 CORS_ORIGINS 配置
# 404 错误 → 检查 NEXT_PUBLIC_API_URL 配置
```

### 10.6 Go 网关 502 Bad Gateway

```bash
# 1. 检查 Python 后端是否运行
curl http://localhost:8000/health

# 2. 检查 Go 网关到后端的连接
docker compose logs nexus_gate | grep "proxy"

# 3. 检查 NEXUS_AI_HOST/PORT 配置
# .env 中应配置为:
# NEXUS_AI_HOST=127.0.0.1
# NEXUS_AI_PORT=8000
```

### 10.7 数据库连接池耗尽

```bash
# 症状: API 返回 500, 日志中出现 "Too many connections"
# 解决:
# 1. 增加 MySQL 连接池大小
# 编辑 backend_design/nexus/core/db_manager.py 中的 maxsize
# 2. 检查是否有未关闭的数据库连接
# 3. 重启后端服务
docker compose restart nexus_ai
```

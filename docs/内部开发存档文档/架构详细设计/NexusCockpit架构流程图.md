## 2. 三层记忆体系数据流

```
┌─────────────────────────────────────────────────────────┐
│                    用户对话输入                            │
└───────────────────────────┬──────────────────────────────┘
                             │
              ┌──────────────▼──────────────┐
              │     短期记忆 (Redis)        │
              │  SessionStore + 滚动摘要    │
              │  TTL: 24h (可配置+自动续期) │
              └──────────────┬──────────────┘
                             │ (异步提取)
              ┌──────────────▼──────────────┐
              │     长期记忆 (Milvus+Neo4j)  │
              │  向量检索 + 图谱关系         │
              │  GraphRAG 三路融合:         │
              │  向量 + 图谱 + BM25         │
              │  → RRF 融合 → Rerank       │
              └──────────────┬──────────────┘
                             │ (频次加权)
              ┌──────────────▼──────────────┐
              │     习惯记忆 (MySQL)        │
              │  user_habits 表             │
              │  hit_count 频次加权          │
              └──────────────────────────────┘
```
